## Flashing the firmware

1. build a firmware using `just build-fw` and flash it to the badge.
2. build a system-file using `just build-system <System-identifier>` to build one from pluralkit (`-s something` for pronouns.cc??)
3. flash the .uf2 file to the badge


## Usage

### System name
B => Badge information
C => Member overview

### Badge information
B => System name

### Member overview
C => Add Co-front
B => Edit selected Member
Up / Down => Select Member

### Edit Selected Member
Up / Down => Switch Member
B => Member Overview
C => Remove Co-front / System name
